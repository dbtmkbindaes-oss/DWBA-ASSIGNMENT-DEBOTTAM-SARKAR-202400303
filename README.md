## 🔹 Data Preparation

### `prepare_data.py`

This script is responsible for preparing and processing the input data before the MapReduce workflow is executed.

It organizes the required data into a format suitable for further processing.

---

## 🔹 Mapper

### `mapper.py`

This file implements the **Mapper** stage of the MapReduce process.

The Mapper processes the input records and generates intermediate **key-value pairs** that can be passed to the Reducer.

---

## 🔹 Reducer

### `reducer.py`

This file implements the **Reducer** stage.

The Reducer processes the intermediate key-value pairs produced by the Mapper and performs the required aggregation to generate the final results.

---

## 🔹 MapReduce Execution

### `run_mapreduce.py`

This is the main execution script for the MapReduce workflow.

It coordinates the different stages of the processing pipeline and produces the required output.

---

## 🔹 Output Files

### `all_subjects_grades.txt`

Contains the processed grade information for the subjects.

### `grade_distribution_by_subject.csv`

Contains the calculated grade distribution for different subjects in CSV format.

### `grade_distribution_chart.png`

Provides a graphical representation of the grade distribution by subject.

### `metadata[1].json`

Contains supporting metadata associated with the dataset or processing task.
