## ⚙️ MapReduce Implementation

The MapReduce implementation is divided into multiple Python files:

### `prepare_data.py`

Prepares and processes the input data before it is passed to the MapReduce pipeline.

### `mapper.py`

Implements the **Mapper** stage.

The mapper reads the input records, processes them, and generates intermediate key-value pairs.

### `reducer.py`

Implements the **Reducer** stage.

The reducer receives the intermediate key-value pairs generated by the mapper and aggregates the results.

### `run_mapreduce.py`

Acts as the main execution script for running the MapReduce workflow.

It coordinates the required processing steps and generates the final results.
